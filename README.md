# 🌤️ WeatherNow — Live Weather Dashboard
# Access live dashboard here- https://ashwinihebbali.github.io/WeatherNow-Live-Weather-Dashboard/
## ✨ Features
- 🔍 Search any city in the world
- 🌡️ Real-time temperature, humidity, wind, pressure, visibility
- 🕐 Hourly forecast for today
- 📅 5-day forecast with precipitation probability
- 🌗 Dynamic animated backgrounds (sunny, rainy, stormy, snowy, night…)
- ✨ Animated particles — raindrops, snowflakes, fog wisps, lightning flashes
- 🔄 °C / °F unit toggle
- 📱 Fully responsive

## 🚀 Run locally
No install needed — just open in any browser:
```
index.html  →  double-click or drag into browser
```

## 🛠️ Tech Stack
- HTML5 · CSS3 (glassmorphism, keyframe animations, CSS Grid)
- Vanilla JavaScript (ES2020, Fetch API, async/await)
- Visual Crossing Weather API
